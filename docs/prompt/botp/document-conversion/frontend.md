# BOTP 单据转换前端开发提示词

在 `matrix-web` 中新增 BOTP 管理入口，使用 Vue 3、Vite、Axios 和现有页面风格。

首版页面：

1. 规则列表：查询规则、显示源单/目标单、版本和状态。
2. 规则详情：展示单头映射、分录映射和反写配置。
3. 转换预览：输入规则编码和源单引用，调用 `/api/botp/executions/preview`，展示目标草稿。
4. 执行中心：提交同步执行并按 executionId 查询结果。

约束：

- API 请求统一放在 `src/api/botp.js`。
- 不允许在页面中拼接数据库字段或执行任意表达式。
- 字段映射必须由后端元数据返回。
- 错误信息应显示后端业务 message。
- 页面先采用表单和表格，不在 V1 引入复杂拖拽连线设计器。

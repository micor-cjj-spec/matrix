# 财务月结工作台数据字典

## closeStatus

| 值 | 含义 |
|---|---|
| READY | 首版检查通过，可进入关账建议 |
| WARNING | 有预警或待确认事项 |
| BLOCKED | 有阻塞项，不建议关账 |
| CLOSED | 当前期间已关闭 |

## checkItems.status

| 值 | 含义 |
|---|---|
| PASSED | 通过 |
| WARNING | 预警 |
| BLOCKED | 阻塞 |
| PENDING | 待确认 |

## checkItems.category

| 值 | 含义 |
|---|---|
| FOUNDATION | 基础资料 |
| VOUCHER | 凭证 |
| LEDGER | 总账 |
| PERIOD_END | 期末处理 |
| REPORT | 报表 |
| CLOSE | 关账 |

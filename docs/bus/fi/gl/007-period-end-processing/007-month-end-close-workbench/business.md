# 财务月结工作台业务说明

## 1. 业务名称

财务月结工作台 / 关账前检查中心。

## 2. 业务背景

总账域已经存在凭证、账表查询、现金流、往来、期末处理和分析报表等能力，但月末关账前缺少统一入口来回答“当前期间是否可以关账”。财务人员需要在多个页面之间切换，才能确认基础资料、会计期间、凭证过账、期末处理和报表生成情况。

## 3. 业务目标

首版目标是提供只读型关账前检查中心：

- 按业务单元和会计期间汇总月结准备度
- 识别阻塞项、预警项、待确认项和通过项
- 复用现有期末处理模块结果
- 提供问题处理下钻入口
- 不直接关闭期间，不做反结账，不新增审批流

## 4. 业务定位

本场景属于总账期末处理域，是期末处理监控中心的上层工作台。监控中心偏模块状态，月结工作台偏关账决策和阻塞收敛。

## 5. 与其他业务的关系

- 凭证处理：检查当前期间凭证数量、过账数量、未过账数量和异常凭证数量。
- 总账分录：检查当前期间总账借贷是否平衡。
- 基础资料健康检查：复用已存在的科目、报表映射等基础数据检查结果。
- 期末处理：汇总结转损益、自动转账、期末调汇、凭证摊销、期末结账模块状态。
- 报表分析：检查资产负债表、利润表、现金流量表是否可生成。

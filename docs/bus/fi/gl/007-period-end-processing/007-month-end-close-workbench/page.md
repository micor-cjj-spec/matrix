# 页面说明

## 1. 页面入口

入口位于总账首页的“期末处理”分组，名称为“月结工作台”。

## 2. 查询区

- 业务单元选择
- 会计期间输入
- 查询按钮
- 重置按钮

## 3. 概览区

展示：

- 关账准备状态
- 准备度分数
- 阻塞项数量
- 待处理凭证数量
- 期间状态、本位币、当前期间等辅助信息

## 4. 关账前检查项

以表格展示检查项：

- 类别
- 检查项名称
- 状态
- 严重级别
- 说明
- 建议动作
- 下钻按钮

## 5. 月结步骤

展示期末处理模块状态：

- 结转损益
- 自动转账
- 期末调汇
- 凭证摊销
- 期末结账
- 报表生成

## 6. 交互规则

- 点击下钻按钮跳转到对应业务页面。
- 查询失败时展示错误提示，不保留过期检查项。
- 当前期间已关闭时展示为已关账复核状态。

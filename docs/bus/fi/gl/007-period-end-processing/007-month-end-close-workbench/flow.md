# 流程设计

## 1. 查询流程

1. 用户进入财务月结工作台。
2. 前端默认加载业务单元列表，并默认选择第一个业务单元。
3. 用户选择业务单元和期间。
4. 前端请求关账前检查接口。
5. 后端解析期间，聚合基础资料、会计期间、凭证、总账分录、期末处理模块和报表生成检查结果。
6. 前端展示准备度、检查项、期末步骤和阻塞提示。

## 2. 状态定义

| 状态 | 含义 |
|---|---|
| READY | 当前期间满足首版关账前检查条件 |
| WARNING | 有预警或待确认事项，但没有强阻塞 |
| BLOCKED | 存在阻塞项，不建议关账 |
| CLOSED | 当前期间已经关闭 |

## 3. 检查项状态

| 状态 | 含义 |
|---|---|
| PASSED | 检查通过 |
| WARNING | 需要关注，但首版不强制阻塞 |
| BLOCKED | 阻塞关账建议 |
| PENDING | 条件不足或需要用户确认 |

## 4. 首版不包含的流程

- 不直接执行关账
- 不执行反结账
- 不新增关账审批流
- 不保存检查批次

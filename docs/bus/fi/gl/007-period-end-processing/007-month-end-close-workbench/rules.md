# 业务规则

## 1. 强阻塞规则

以下情况判定为阻塞项：

- 会计期间档案不存在
- 期间状态不是可关账状态且不是已关闭复核
- 当前期间存在未过账凭证
- 当前期间总账分录借贷不平衡
- 基础资料健康检查存在高风险问题

## 2. 预警规则

以下情况判定为预警：

- 当前期间没有凭证
- 期末处理模块未识别到相关凭证，需要人工确认是否无需处理
- 报表生成存在警告
- 现金流量表、资产负债表或利润表生成失败

## 3. 通过规则

检查项没有阻塞且没有预警时，状态为通过。

## 4. 准备度规则

准备度按检查项计算：

- 通过项得满分
- 预警项和待确认项得半分
- 阻塞项不得分

首版按简单比例计算 0-100 分。

## 5. 关账建议

只有当阻塞项数量为 0，且期间未关闭时，`canClose` 才可能为 `true`。首版仅给出建议，不执行关账。

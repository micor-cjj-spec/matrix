# 流程设计

## 1. 生成检查批次

1. 用户在月结工作台选择业务单元和期间。
2. 点击“生成检查批次”。
3. 后端重新执行月结工作台检查，生成结果快照。
4. 后端生成批次号并保存批次。
5. 批次申请状态默认为 `DRAFT`。

## 2. 提交关账申请

1. 用户在历史批次列表中选择批次。
2. 只有阻塞项数量为 0 的批次允许提交。
3. 提交后状态从 `DRAFT` 变为 `SUBMITTED`。

## 3. 批准申请

1. 首版不接入审批流，仅提供批准状态动作。
2. 状态从 `SUBMITTED` 变为 `APPROVED`。
3. `APPROVED` 不代表期间已正式关闭。

## 4. 禁止动作

- `BLOCKED` 批次不能提交。
- `APPROVED` 批次不能重复提交。
- 首版不支持撤回、驳回、作废。

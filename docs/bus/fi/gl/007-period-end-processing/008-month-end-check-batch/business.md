# 月结检查批次业务说明

## 1. 业务名称

月结检查批次留痕与关账申请底座。

## 2. 业务背景

月结工作台可以实时判断当前期间是否具备关账条件，但实时结果无法作为关账依据留存。财务月结需要明确某一次检查在什么时间、由谁生成、检查结果如何、是否存在阻塞项，并基于该检查批次发起后续关账申请。

## 3. 业务目标

- 保存某次月结检查结果快照。
- 为每次检查生成批次号。
- 支持历史批次查询和详情查看。
- 基于无阻塞批次发起关账申请。
- 支持申请状态流转到提交和批准。

## 4. 首版边界

- 不直接修改会计期间状态。
- 不执行正式关账。
- 不实现复杂审批流。
- 不做反关账。

## 5. 与其他业务关系

- 依赖月结工作台实时检查结果。
- 后续正式关账可引用已批准批次。
- 会计期间状态更新和审计日志后续独立建模。

# 字段说明

## 归档包

| 字段 | 含义 |
| --- | --- |
| forg | 业务单元 |
| period | 会计期间 |
| archiveStatus | 归档状态 |
| conclusion | 归档结论 |
| generatedAt | 生成时间 |
| readinessScore | 准备度 |
| blockingCount | 阻塞项数量 |
| warningCount | 预警数量 |
| pendingCount | 待确认数量 |
| periodVoucherCount | 本期凭证数 |
| postedVoucherCount | 已过账凭证数 |
| closeExecuted | 是否已执行关账 |
| periodRolled | 是否已启用下一期间 |
| checkBatch | 最新检查批次 |
| closeExecution | 最新关账执行记录 |
| periodRollover | 最新期间滚动记录 |
| milestones | 里程碑 |
| warnings | 遗留提示 |

## 里程碑

| 字段 | 含义 |
| --- | --- |
| code | 里程碑编码 |
| name | 里程碑名称 |
| status | 状态 |
| time | 发生时间 |
| operator | 操作人 |
| summary | 摘要 |

# 业务说明

## 目标

在月结正式关账后，将组织财务参数的当前期间推进到下一会计期间，确保后续凭证、期末处理、报表默认进入新期间。

## 使用对象

- 财务主管：关账后启用下一期间。
- 财务人员：进入新期间继续日常业务。
- 审计/运维：查看期间滚动日志。

## 核心价值

- 避免关账后默认期间仍停留在已关闭月份。
- 自动创建下一会计期间，减少手工维护。
- 通过滚动记录追踪从哪个关账执行记录推进到哪个期间。

## 成功标准

- 已成功关账执行记录可以启用下一期间。
- 下一期间不存在时自动创建 `OPEN` 期间。
- 组织财务参数 `fcurrentPeriod` 更新为下一期间。
- 期间滚动记录可查询。

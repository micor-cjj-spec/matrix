# 规则：报表映射缺口治理建议

## 推荐规则
- 利润表缺口：
  - 科目编码以 `5` 开头或名称包含“收入”时，推荐 `PL_REVENUE`。
  - 科目编码以 `6`、`7` 开头或名称包含“成本”“费用”时，推荐 `PL_COST`。
  - 科目编码以 `1`、`2`、`3`、`4` 开头时，不自动推荐利润表项目，提示先核实凭证或报表口径。
- 资产负债表缺口：
  - 科目编码以 `100` 开头或名称包含“现金”“银行”时，推荐 `BS_CASH`。
  - 科目编码以 `1` 开头时，推荐 `BS_ASSET`。
  - 科目编码以 `2`、`3`、`4` 开头时，推荐 `BS_LIAB_EQ`。
- 其他情况：
  - 只展示人工确认提示，不自动预填报表项目。

## 安全规则
- 推荐只作为辅助，不自动保存。
- 无法匹配模板报表项目时，不写入 `fitemId`。
- 生产验证不创建真实映射数据。

# 业务说明：报表映射缺口连续治理队列

## 业务问题
关账前检查中，报表映射缺口通常是一组待处理事项。当前单缺口治理已经能跳转到映射页，但用户缺少“当前第几个、下一条是什么”的连续处理感，容易遗漏。

## 目标用户
- 总账会计
- 财务报表维护人员
- 关账前检查人员

## 业务目标
- 缺口列表能作为一个待办队列进入治理。
- 映射页能展示当前缺口在队列中的位置。
- 用户能在映射页直接切换上一条/下一条缺口。
- 不可靠推荐仍只提示原因，不强制预填报表项目。

## 成功标准
- 从企业纳税表任一缺口进入映射页后，能看到队列进度。
- 下一条/上一条切换会重新带入对应科目、模板、建议和推荐项目。
- 返回来源报表复核仍可用。

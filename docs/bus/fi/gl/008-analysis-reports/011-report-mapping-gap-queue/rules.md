# 规则说明：报表映射缺口连续治理队列

## 队列规则
- 队列来源为企业纳税表接口返回的 `mappingGaps`。
- 队列顺序保持接口返回顺序。
- 队列只携带治理导航字段，不作为保存依据。
- 当前缺口下标从 0 开始在路由中传递，页面展示时转为从 1 开始。

## 推荐规则
- 如果缺口建议存在可靠 `recommendedItemCode`，映射页优先按该编码匹配报表项目。
- 如果没有可靠推荐编码，映射页展示来源建议，但不自动预填报表项目。

## 回跳规则
- `返回来源报表复核` 回到来源报表并保留期间、币种、业务单元。
- 保存新增映射后的自动复核逻辑保持原有行为。

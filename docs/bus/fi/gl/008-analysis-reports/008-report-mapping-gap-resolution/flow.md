# 业务流程

1. 用户打开企业纳税表。
2. 系统展示 `mappingGaps`。
3. 用户点击缺口行的“维护映射”。
4. 系统进入 `/ledger/report-account-map`，携带 `mode=resolve`、`accountCode`、`reportType`、`templateId`、来源报表参数。
5. 映射页加载模板、报表项目、会计科目。
6. 映射页定位模板和科目，展示治理上下文。
7. 映射页自动打开新增映射弹窗并预填可确定字段。
8. 用户选择报表项目并保存。
9. 系统保存映射并展示返回来源报表复核按钮。
10. 用户返回来源报表，重新查询并确认缺口状态。

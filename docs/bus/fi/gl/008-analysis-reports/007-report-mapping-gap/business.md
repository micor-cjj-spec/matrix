# 报表科目映射缺口治理业务说明

## 1. 业务名称
报表科目映射缺口治理

## 2. 业务定位
本功能用于把报表生成过程中的未映射科目从普通告警升级为可处理待办，帮助财务在月结、报表出具和纳税分析前及时补齐科目到报表项目的映射关系。

## 3. 业务目标
- 暴露未映射科目的结构化信息。
- 从报表页面直接跳转到报表科目映射维护页。
- 降低报表漏项和月结复核成本。

## 4. 当前能力
- 利润表、资产负债表聚合时可识别未映射科目。
- 企业纳税表可透传利润表映射缺口。
- 前端企业纳税表可展示缺口并跳转处理。

## 5. 代码对齐结论
当前功能基于既有报表聚合和报表科目映射维护能力增强，不新增落库表，不自动生成映射关系。

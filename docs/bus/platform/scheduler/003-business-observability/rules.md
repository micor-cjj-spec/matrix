# 业务规则

1. 进度必须在 0-100 之间，且不能倒退。
2. 只有执行实例所属 executorCode 可以上报进度和最终状态。
3. 人工操作原因必填，所有操作必须保留审计日志。
4. `RETRY_NOW` 仅允许用于 RETRY_WAIT 或已经终止的异常实例。
5. 终止自动重试后，实例回到 FAILED 或 TIMEOUT，不再由扫描器创建后续尝试。
6. 运行中或已投递任务的取消只改变平台状态；业务 Handler 仍需自行实现幂等和协作式停止。
7. `SKIP` 只允许用于 WAITING、CREATED、RETRY_WAIT，已进入 QUEUED 的消息不得假定能够撤回。
8. `MARK_SUCCESS` 只允许用于 RETRY_WAIT 或已终止的异常实例，不允许对 CREATED、QUEUED、RUNNING 人工标记成功。
9. 人工终态操作需要将尚未投递的 PENDING/FAILED Outbox 标记为 CANCELLED；发布器发送前再次确认执行实例非终态。
10. 告警通过唯一 dedupeKey 去重，多实例扫描不能产生重复记录。
11. 凭证期间检查发现业务问题时返回业务失败，由任务配置决定是否自动重试。
12. 凭证期间检查和期末结账预检查当前仅支持全账簿范围，传入 bookId 必须明确拒绝。
13. 期末结账预检查只有在未过账凭证、凭证问题和科目差异均为 0 时通过。
14. 财务报表快照按 executionNo 唯一，重复执行回调不得重复插入。

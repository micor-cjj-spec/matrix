# 业务规则

1. 进度必须在 0-100 之间，且不能倒退。
2. 只有执行实例所属 executorCode 可以上报进度和最终状态。
3. 人工操作原因必填，所有操作必须保留审计日志。
4. `RETRY_NOW` 仅允许用于 RETRY_WAIT 或已经终止的异常实例。
5. 终止自动重试后，实例回到 FAILED 或 TIMEOUT，不再由扫描器创建后续尝试。
6. 运行中任务的取消只改变平台状态；业务 Handler 仍需自行实现幂等和协作式停止。
7. 告警通过唯一 dedupeKey 去重，多实例扫描不能产生重复记录。
8. 凭证期间检查发现业务问题时返回业务失败，由任务配置决定是否自动重试。
9. 期末结账预检查只有在未过账凭证、凭证问题和科目差异均为 0 时通过。
10. 财务报表快照按 executionNo 唯一，重复执行回调不得重复插入。

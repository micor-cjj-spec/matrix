# 真实业务接入与运行可观测性

## 业务目标

第三期将调度平台从技术链路验证推进到真实财务业务试运行，并提供可观察、可补偿、可审计的运行能力。

## 本期范围

- `fi-service` 接入凭证期间检查、财务报表生成、期末结账预检查。
- 长任务通过进度、阶段和说明持续上报。
- 管理员可对异常执行进行立即重试、终止重试、取消、跳过和标记成功。
- 所有人工操作必须记录操作人、原因、原状态和新状态。
- 最终失败、超时、DEAD 和执行器离线生成去重告警。
- 提供运行看板与 Prometheus 基础指标。

## 当前边界

- 告警目前完成落库、查询和确认，尚未接通 IM、邮件或飞书投递。
- 取消运行中任务属于协作式取消的前置能力，当前不能强制终止远程 Java 线程。
- 财务报表第一版提供科目借贷发生额和净额快照，不等同于完整法定财务报表。
- 代码已实现，仍需执行数据库脚本并完成端到端部署验证。

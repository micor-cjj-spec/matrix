# 定时任务调度业务说明

## 业务目标

为 Matrix 平台及外部业务系统提供统一的动态任务调度能力。用户可在前台配置 Cron 表达式、时区、执行器和失败策略；外部系统可通过幂等 OpenAPI 创建任务。

## 核心对象

- 任务定义：描述何时触发、由谁执行以及执行策略。
- 执行实例：记录每一次计划触发或人工触发。
- Outbox 事件：保证执行实例落库与 RabbitMQ 投递最终一致。
- 执行器：消费调度消息并通过回调更新执行状态。

## 当前交付

- 动态 Cron 创建、修改、暂停、恢复、删除和立即执行。
- Quartz JDBC 集群配置与 Misfire 策略。
- `PLATFORM` 与 `OPEN_API` 两类任务来源。
- `sourceService + requestId` 幂等创建。
- 执行实例、Outbox 投递、指数退避和结果回调。
- 前端任务列表、编辑表单、Cron 预览和执行记录。

## 后续范围

- 执行器注册与心跳。
- OpenAPI HMAC 签名和调用方配额。
- HTTP 执行器白名单。
- 失败任务自动重试、告警和人工补偿。
- 分片任务、依赖任务和 DAG 工作流。

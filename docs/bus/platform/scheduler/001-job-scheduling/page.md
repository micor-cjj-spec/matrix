# 定时任务调度页面

## 路由

`/scheduler/jobs`

## 任务列表

展示任务编码、任务名称、来源系统、Cron、时区、执行器、状态、上次执行时间和下次执行时间。

支持操作：

- 新建和编辑
- 暂停和恢复
- 立即执行
- 查看执行记录
- 删除

## 任务表单

字段包括：

- 任务编码、任务名称
- Cron 表达式、时区
- 执行类型、执行器编码、处理器编码
- JSON 参数
- 并发策略、Misfire 策略
- 超时和重试配置

Cron 输入变化后可预览未来五次执行时间。

## 执行记录

展示执行编号、计划时间、触发方式、执行器、处理器、状态、错误信息和更新时间。后续增加日志流和重试链路。

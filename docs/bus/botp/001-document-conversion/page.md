# 单据下推反写页面设计

## 页面一：规则列表

展示规则编码、名称、源单类型、目标单类型、当前版本、状态、更新时间。支持新建、复制、测试、发布、停用和查看版本。

## 页面二：规则设计器

页签：

1. 基本信息：规则名称、源系统、源单、目标系统、目标单。
2. 单头映射：来源类型、源字段、目标字段、常量、必填。
3. 分录映射：源分录字段与目标分录字段一对一映射。
4. 反写规则：目标事件、来源字段、目标字段、反写模式。
5. 执行设置：同步/异步、超时、重试、权限。

字段必须从单据元数据中选择，不允许自由输入数据库字段或 SQL。

## 页面三：规则预览

输入源单编号或选择源单，展示：

- 源单原始数据。
- 当前规则版本。
- 单头映射结果。
- 分录映射结果。
- 目标单草稿。
- 必填校验错误和警告。

## 页面四：执行中心

展示执行 ID、请求号、来源系统、规则及版本、源单、目标单、状态、失败阶段、重试次数和时间。支持查看详情、重试反写和查询上下游。

## 页面五：单据关系查询

支持从源单向下查询目标单，也支持从目标单反查源单；展示分录级关联数量、金额和有效状态。

## V1 前端边界

本阶段以后端 API 和交互契约为主。前端首版应优先完成规则列表、规则设计器、预览和执行中心，复杂可视化连线设计器放到后续版本。

# 单据下推反写流程

## 预览流程

1. 校验请求和规则状态。
2. 根据规则编码取得已发布版本。
3. 通过源单适配器读取源单。
4. 执行源单业务校验。
5. 执行单头和分录字段映射。
6. 返回目标单草稿、规则版本和警告信息。
7. 不创建目标单、不保存关联、不执行反写。

## 同步下推流程

1. 以 `tenantId + sourceSystem + requestId` 检查幂等结果。
2. 创建执行任务，状态为 CREATED。
3. 加载已发布规则版本。
4. 逐个加载源单并校验。
5. 生成目标单草稿。
6. 按执行 ID 和目标分组号生成目标创建幂等键。
7. 先查询目标系统是否已存在相同幂等键的单据。
8. 不存在时调用目标适配器创建目标单。
9. 记录目标单结果和上下游关系。
10. 执行反写；反写失败则进入 WRITEBACK_PENDING。
11. 完成后状态为 SUCCEEDED。

## 超时处理

目标系统调用超时时，不直接重新创建目标单。必须先根据目标创建幂等键查询目标系统：

- 已存在：补录目标结果并继续关联和反写。
- 不存在：允许重试创建。
- 状态未知：保留 TARGET_CREATING，进入人工或定时核查。

## 反向处理

目标单作废、删除、冲销或关闭时：

1. 将对应关系标记为无效。
2. 按有效关联关系重新计算源单累计量。
3. 反写已下推量、剩余量和下推状态。
4. 保存反向处理日志。

# 单据下推反写业务说明

## 业务定位

BOTP 是独立于具体业务域的单据转换平台。它读取已发布的转换规则，通过源单适配器加载业务数据，生成目标单草稿，再调用目标单据领域接口创建目标单，并维护上下游关系和反写状态。

## 参与方

- 规则管理员：配置、测试、发布和停用转换规则。
- 业务用户：在源单页面发起下推或预览。
- 外部系统：通过开放 API 调用下推能力。
- 源单服务：提供源单读取、校验和反写接口。
- 目标单服务：提供目标单幂等创建和状态查询接口。
- BOTP 平台：负责编排、映射、幂等、关系和执行追踪。

## 核心业务对象

- 单据类型：描述单头、分录及字段元数据。
- 转换规则：描述源单、目标单和触发条件。
- 规则版本：保存一次不可变的发布快照。
- 字段映射：描述源字段、常量或上下文到目标字段的映射。
- 执行任务：记录一次预览或真实下推的完整状态。
- 单据关系：记录源单、目标单及分录级数量金额关系。
- 反写任务：记录目标创建后对源单的覆盖、重算或状态迁移。

## V1 业务能力

1. 查询可用规则。
2. 根据规则和源单引用生成目标草稿。
3. 调用目标适配器幂等创建目标单。
4. 保存或返回执行状态。
5. 相同请求号重复调用不重复创建目标单。
6. 通过适配器隔离内部服务和外部系统差异。

## 业务边界

BOTP 不负责目标单据自身的编码、权限、审核、预算、库存或会计校验。这些规则必须由目标单据领域服务执行。BOTP 仅负责跨单据转换和流程编排。

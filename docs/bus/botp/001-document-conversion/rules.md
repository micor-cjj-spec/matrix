# 单据下推反写规则

## 规则发布

1. 草稿规则可以修改。
2. 发布时生成不可变版本快照。
3. 已发布版本不能覆盖修改；调整必须产生新版本。
4. 执行任务必须保存规则编码和版本。

## 映射规则

V1 仅允许以下字段来源：

- `SOURCE_FIELD`：从源单 Map 中按点路径取值。
- `CONSTANT`：使用规则配置的固定值。
- `CONTEXT`：从执行参数中按点路径取值。

V1 禁止配置 SQL、Groovy、JavaScript、SpEL 和任意 Java 类名。

## 必填校验

映射标记为 `required=true` 时，结果为 null、空字符串或空集合均视为失败，且不得继续创建目标单。

## 适配器规则

1. 每个适配器必须声明支持的系统和单据类型。
2. 同一系统、同一单据类型只能存在一个启用适配器。
3. BOTP 不允许绕过适配器直接写业务表。
4. 目标适配器必须支持幂等创建或幂等查询。

## 幂等规则

外部请求幂等键：

`tenantId + sourceSystem + requestId`

目标创建幂等键：

`botp:{tenantId}:{executionId}:{targetIndex}`

相同外部幂等键重复调用时返回第一次执行结果。

## 状态规则

- 目标未创建前失败：可以从转换或创建阶段重试。
- 目标已创建、关系未保存：只能补保存关系。
- 目标已创建、反写失败：状态进入 WRITEBACK_PENDING，只重试反写。
- 不允许因为反写失败再次创建目标单。

## 反写规则

累计数量或金额优先通过有效关系重算，不使用无保护的简单加减。目标单反审核、作废或删除时，先失效关系，再重新计算源单状态。

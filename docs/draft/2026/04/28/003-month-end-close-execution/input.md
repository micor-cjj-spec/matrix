# 关账执行中心草稿输入

## 需求

在“财务月结工作台 / 关账前检查中心”基础上，新增关账执行中心能力。已批准的月结检查批次可发起正式关账，系统需要执行前复检、关闭会计期间、记录执行日志，并在前端展示执行结果。

## 背景

- 已有月结工作台提供关账前检查。
- 已有检查批次留痕与提交/批准状态。
- 现有会计期间服务已具备按期间 ID 关闭的底层能力。

## 约束

- 不绕过检查批次直接从工作台关账。
- 不允许未批准批次执行关账。
- 执行前必须复跑当前关账检查，避免批准后业务数据变化。
- 本期存在阻塞项、预警项、待确认项时不执行正式关账。
- 成功执行后必须有执行记录。

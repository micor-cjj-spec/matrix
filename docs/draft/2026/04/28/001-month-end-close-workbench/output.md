# AI 输出结果

## 场景定位

财务月结工作台 / 关账前检查中心用于把现有总账能力串成月末关账前的统一检查入口。

当前代码已经具备以下基础能力：

- 期末处理模块：结转损益、自动转账、期末调汇、凭证摊销、期末结账、监控中心
- 凭证与总账分录数据
- 基础资料健康检查
- 报表查询与现金流量表能力
- 前端总账首页与期末处理页面

## 建议首版范围

首版实现为只读型检查工作台，不直接关闭期间，不做反结账，不新增审批流。

首版重点：

1. 按业务单元和期间执行关账前检查
2. 展示月结准备度、阻塞项、预警项和通过项
3. 汇总现有期末处理模块状态
4. 检查基础资料、会计期间、凭证过账、总账借贷平衡、报表可生成性
5. 提供前端下钻入口，引导用户回到凭证、期末处理、报表和基础资料页面处理问题

## 后续扩展

- 关账申请 / 审批
- 正式关账 / 反关账动作
- 检查批次保存与审计日志
- 检查项规则配置化
- 与消息通知和任务中心联动

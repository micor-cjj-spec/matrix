# AI 输出结果

## 场景定位

月结工作台当前是实时检查视图。下一步需要将某一次检查结果保存为可追溯批次，作为后续关账申请、审批、正式关账和审计的依据。

## 首版建议

1. 支持基于当前组织和期间生成检查批次。
2. 保存工作台检查结果快照，包括准备度、阻塞项、预警项、检查项和月结步骤。
3. 支持查询历史批次。
4. 支持关账申请底座状态流转：`DRAFT -> SUBMITTED -> APPROVED`。
5. 有阻塞项的批次不允许提交申请。
6. 首版仍不直接修改会计期间状态。

## 与上一阶段关系

本场景依赖 `007-month-end-close-workbench` 的检查结果，不重新定义检查规则。

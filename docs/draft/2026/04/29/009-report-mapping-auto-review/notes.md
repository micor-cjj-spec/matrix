# 草稿记录

## 核心流程
1. 用户在企业纳税表点击“维护映射”。
2. 用户在报表科目映射弹窗中保存映射。
3. 系统携带 `review=reportMappingResolution` 回到企业纳税表。
4. 企业纳税表重新加载数据后，用 `resolvedAccountCode` 与当前 `mappingGaps` 比对。
5. 若缺口不存在，展示复核通过；若仍存在，展示仍需处理。

## 设计取舍
- 不在本轮强制创建线上测试映射，避免污染现有数据。
- 自动复核依赖来源报表重新查询后的 `mappingGaps`，不单独新增后端复核接口。
- 保持普通映射维护流程不受影响。

# 月结归档包草稿输入

## 需求

在月结闭环完成后，提供按组织与期间查询的月结归档包。归档包需要汇总关账前检查、检查批次、审批、关账执行、期间滚动等信息，形成可审计、可追溯的月结报告中心。

## 背景

已完成能力：

- 007 月结工作台 / 关账前检查中心。
- 008 月结检查批次留痕 / 关账申请底座。
- 009 关账执行中心 / 期间关闭动作。
- 010 财务期间滚动 / 下一期间初始化中心。

当前缺口：

- 财务主管和审计人员需要在一个视图里看到完整月结链路。
- 检查、审批、执行、滚动记录分散在不同接口中。

## 约束

- 第一版先做页面与接口，不做 PDF/Excel 导出。
- 不新增归档持久化表，先基于现有记录实时聚合。
- 不修改既有关账状态。

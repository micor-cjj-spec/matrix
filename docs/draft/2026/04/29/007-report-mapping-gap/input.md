# 报表科目映射缺口治理需求草稿

## 背景
企业纳税表上线验证时出现 `Unmapped profit-statement accounts: 1001-库存现金` 告警。该告警说明总账发生额无法落到利润表项目，但当前系统只展示文本，财务人员无法直接进入维护动作。

## 用户故事
作为财务主管，我希望在企业纳税表、利润表等报表页面看到未映射科目的结构化待办，并能一键跳转到报表科目映射页处理，避免月结和报表出具时遗漏映射。

## 范围
- 后端返回结构化映射缺口 `mappingGaps`。
- 企业纳税表展示映射缺口清单和处理入口。
- 报表科目映射页支持根据科目编码自动定位筛选。

## 非范围
- 不自动创建映射关系。
- 不改变总账凭证、科目、报表项目的现有数据结构。
- 不接入审批流或任务中心。

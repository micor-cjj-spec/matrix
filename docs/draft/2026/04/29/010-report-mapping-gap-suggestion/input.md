# 需求输入：报表映射缺口治理建议

## 背景
- 企业纳税表已经能暴露报表科目映射缺口，并能跳转到报表科目映射页治理。
- 映射页已经能根据来源参数自动打开新增映射弹窗，并在保存后返回来源报表复核。
- 当前缺口卡片只告诉用户“缺口存在”，没有解释该科目应如何判断，也没有把推荐治理思路带到映射页。

## 本轮目标
- 在企业纳税表缺口卡片中展示治理建议。
- 当缺口可推断推荐报表项目编码时，跳转映射页后自动带入该推荐项目。
- 当缺口不适合自动推荐时，给出诊断提示，帮助用户先判断凭证科目、报表口径或模板设置。

## 非目标
- 不新增后端表结构。
- 不直接批量创建报表科目映射。
- 不在生产环境自动写入测试映射数据。

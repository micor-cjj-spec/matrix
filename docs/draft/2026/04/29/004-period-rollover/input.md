# 财务期间滚动草稿输入

## 需求

在关账执行完成后，提供“启用下一期间”能力。系统根据已成功关账的执行记录，将组织财务参数中的当前期间推进到下一会计期间，并确保下一会计期间档案存在且为 `OPEN`。

## 背景

- 007 已提供月结工作台。
- 008 已提供检查批次、提交、批准。
- 009 已提供正式关账执行和执行记录。
- 关账后还需要把组织财务参数 `fcurrentPeriod` 推进到下月，否则后续默认期间仍停留在已关账期间。

## 约束

- 仅允许基于成功关账执行记录滚动。
- 不允许绕过关账执行记录直接改当前期间。
- 下一期间若不存在，可以自动创建。
- 下一期间若已关闭，不允许滚动。
- 同一关账执行记录只能滚动一次。

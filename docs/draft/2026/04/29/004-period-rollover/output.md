# 财务期间滚动草稿输出

## 功能范围

1. 新增期间滚动记录表。
2. 新增基于关账执行记录的期间滚动接口。
3. 自动计算下一期间。
4. 自动创建下一会计期间档案。
5. 更新组织财务参数当前期间。
6. 前端展示“启用下一期间”按钮和滚动记录。

## 状态

滚动记录当前只记录成功状态：`SUCCESS`。
